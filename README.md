# ESTRELA — protótipo visual

Protótipo de interface estática e navegável para explorar uma possível experiência de marketplace de serviços. **Não é um marketplace operacional:** não há backend, banco de dados, autenticação, pagamentos, chat ou integrações externas.

## Abrir localmente

Abra `index.html` no navegador. Não é necessário instalar dependências ou configurar credenciais.

## O que dá para experimentar

- Busca demonstrativa por serviço e região entre os perfis de exemplo.
- Filtro visual por categoria.
- Cartões e modal de perfil.
- Menu responsivo e mensagens explicando que ações como entrar, cadastrar e contratar não estão conectadas.

Todos os nomes, perfis, avaliações, preços e localidades exibidos são fictícios e estão identificados como conteúdo **DEMO**. Não use esses dados como informação real.

## Arquivos

- `index.html` — estrutura e conteúdo da experiência.
- `styles.css` — identidade visual responsiva e estilos.
- `app.js` — interações locais do protótipo, sem chamadas de rede.
- `public/brand/estrela-mark.svg` — marca ilustrativa do protótipo.
